# Security

To report a security problem in this plugin or in Enablement Studio, follow the contact in the site's security.txt: https://enablementstudio.ai/.well-known/security.txt

Please do not open a public issue for a security problem.

If a security incident affects people who use this plugin through Cursor's Marketplace, we notify Anysphere at legal@cursor.com promptly, as the Marketplace Publisher Terms ask.
